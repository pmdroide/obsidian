# Obsidian

Obisidian is a game engine royalty free with objective to make development easy and simple to understand.

## Getting started

### Prerequisites

- Git
- VSCode
- .NET 10 SDK 
- DirectX 11

### Building

```
# Clone repo
git clone https://github.com/pmdroide/obsidian.git

# Restore packages
dotnet restore

# Change directory to main project
cd DeferredEngine

# Build and run
dotnet run

```
