Vista already has some basic system using AngleSharp and this are its components:

- UIElement.cs (The Visual Node): Wraps an individual XML element. It handles the structural tree parent/child relationships and translates raw CSS dimensions into absolute Rectangle coordinate bounds inside MonoGame.

- UIStyles.cs (The Data Converter): A purely functional utility script. It extracts layout string properties (e.g., #FF0000, 50%, 200px) and safely evaluates them into strong MonoGame primitives (Color, int).

- UIManager.cs (The Orchestrator): Controls the life cycle. It spins up the AngleSharp context, parses the files, ticks layout recalculations during Update(), and triggers cascading Draw() sweeps using MonoGame’s SpriteBatch.
