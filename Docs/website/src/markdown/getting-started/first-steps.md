# First Steps

> **Getting Started** › First Steps

Ready to build? This page walks you through your first scene and addon.

## Overview

After installing s&box, create a new project from the launcher and open it in the editor.

## Details

- Create a new project from the launcher
- Open the scene editor and add a GameObject
- Attach a component and hit play
- Iterate with hotloading — your C# changes compile in milliseconds
