# Reporting Issues

Report engine, editor, and documentation problems through [GitHub Issues](https://github.com/pmdroide/obsidian/issues).

## Make the problem reproducible

Include:

1. What you expected to happen and what happened instead.
2. The steps needed to reproduce the problem, including the scene or asset involved.
3. The repository commit, Windows version, .NET SDK version, and relevant hardware.
4. Console output, stack traces, screenshots, or a small reproduction when available.
5. Whether the problem occurs in Anvil, the standalone runtime, or both.

For FMOD failures, include the native library version and the initialization log. For content build failures, include the asset’s entry in `Content.mgcb` and the build output.

## Contribute a fix

Read the [contributing guide](https://github.com/pmdroide/obsidian/blob/HEAD/CONTRIBUTING.md) before submitting a pull request. For a documentation correction, the source link at the bottom of each guide opens its Markdown file on GitHub.
